# Professor demo guide

1. Open the homepage and use the global archive search.
2. Open **Keşfet**, choose a cultural path, then select Ebru from Categories.
3. Enter **Miras Yolculuğu** and open the paper arts or calligraphy workshop.
4. Open the collection drawer and continue to the paginated archive search.
5. Visit Kuyum Atölyesi, Harita, then the editor login page.

If production catalogue data is not yet published, the site explains the empty state instead of presenting invented records.
