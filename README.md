# MirasExplorer

Taşınabilir kültürel miras verilerinin güvenli JSON aktarımı için FastAPI ve Next.js uygulaması.

Başlangıç, ortam değişkenleri ve test komutları için [geliştirme rehberi](docs/DEVELOPMENT_SETUP.md) kullanılır. Mimari ve aktarım davranışı sırasıyla [ARCHITECTURE.md](docs/ARCHITECTURE.md) ile [IMPORT_PIPELINE.md](docs/IMPORT_PIPELINE.md) içinde açıklanır.
